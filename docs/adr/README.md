# Catatan keputusan (ADR)

Keputusan produk dan arsitektur yang mengubah skema, API, atau aturan data dicatat di sini (lihat [PRD](../prd.md) bagian 12 dan `architecture_blueprint/08_open_decisions.md`). Satu file per keputusan. Keputusan yang berubah tidak ditimpa: buat ADR baru yang menggantikan, lalu ubah status ADR lama menjadi *Digantikan*.

| ADR | Keputusan PRD | Judul | Status |
| --- | --- | --- | --- |
| [0001](0001-d1-struktur-kelas.md) | D1 | Tingkat, program/jurusan, dan rombel diatur sekolah | Diterima |
| [0002](0002-d4-aturan-absensi.md) | D4 | Batas ubah absensi hari yang sama, sesudahnya koreksi | Diterima |
| [0003](0003-d8-kanal-notifikasi.md) | D8 | Notifikasi dalam aplikasi dulu | Diterima |
| [0004](0004-jadwal-tugas-staf.md) | (FR-8.5) | Jadwal tugas staf sederhana sebelum modul kehadiran pegawai | Diterima |
| [0005](0005-d11-penilaian-rapor.md) | D11 | Penilaian dan rapor Kurikulum Merdeka | Diterima |

**Format:** konteks, keputusan, alasan, konsekuensi (termasuk tempatnya di kode), dan hal yang masih terbuka.
